# Animo Map Design System

## Visual Identity

Animo Map uses a modern, minimal dark-mode design with a teal and blue-green accent palette. Dark mode is the default application theme.

## Color Palette

Use these colors consistently throughout the application:

| Role | Color | Use |
|---|---|---|
| Primary background | `#0B1E26` | Main screen backgrounds |
| Surface / card | `#132F3A` | Cards, panels, and content containers |
| Elevated surface | `#1C3E46` | Elevated cards and interactive surfaces |
| Primary teal | `#2A6F73` | Primary buttons and important UI elements |
| Accent teal | `#43CDBB` | Interactive accents, icons, and active navigation indicators |
| Highlight / selected | `#A7F7DF` | Selected states and prominent highlights |
| Primary text | `#E6F7F5` | Main text and headings |
| Secondary text | `#8FAFB2` | Supporting text, descriptions, and metadata |

Additional colors may be used when functionally necessary, provided they remain visually consistent with the design system.

## Typography

Use Poppins or a visually similar sans-serif font.

| Level | Size | Weight |
|---|---:|---|
| H1 | 24–28sp | Bold |
| H2 | 20–22sp | Bold |
| H3 | 16–18sp | SemiBold |
| Body | 14–16sp | Regular |
| Caption | 12sp | Regular |

## UI Principles

- Keep the appearance modern, minimal, and clean.
- Use rounded cards, buttons, and containers with consistent spacing and alignment.
- Maintain clear hierarchy and readable text.
- Use simple, recognizable icons and teal accents for important actions and selected states.
- Avoid excessive gradients, neon effects, and unnecessary decoration.
- Keep screens visually consistent across the application.

## Wireframes and Design References

When the user supplies wireframes, mockups, screenshots, or other screen references, follow their layout, component placement, hierarchy, and interactions. Apply the Animo Map palette and typography to those layouts. Do not redesign referenced screens or add major UI elements based on assumptions; supplied references take priority over general design assumptions unless the user says otherwise.
